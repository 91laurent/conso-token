CONSO TOKEN — 一页说明

Conso Token 免费：可自由使用、复制、修改和分享（MIT 许可，见 LICENSE.txt）。

它是做什么的
一个小窗口，显示你的 Claude 套餐用到了哪里：已用多少、每天还剩多少、比预期快还是慢。它不做任何预测，
不连接任何网站，也不要求任何密码。

你需要什么
- Windows 10 或 11，无需安装其他东西。
- Claude 桌面应用（你使用 Claude Code 的那个），使用付费的 Claude 套餐，且应用能提供该套餐的用量数据：
  有些套餐不提供这些数据。Conso Token 只用过一种套餐进行试用。

安装（10 分钟，只需一次）
1. 把收到的“Conso Token”文件夹放到电脑的某个磁盘上（例如 H:）。如果收到的是 zip 文件：右键点击
   zip，选择“全部提取”。请保留整个文件夹：conso_token.exe、“outils”文件夹、“licences”文件夹和文本文件。
   不要放在 U 盘或网络磁盘上，文件夹名称中也不要有撇号。
2. 在 Claude 桌面应用中打开一个新的 Claude Code 会话，输入下面这句话，并把路径换成你的文件夹路径：
       读取文件夹“H:\Conso Token”中的 PASTE_INTO_CLAUDE.txt 文件，并严格按其内容操作。
   Claude 会创建一个任务，每 15 分钟把你的数据发送到窗口，当面试运行一次，并告诉你是否成功。当应用
   请求 PowerShell 权限时，请回答“是”或“始终允许”：这是正常的，用于发送数据。
3. 双击 conso_token.exe。如果 Windows 显示“Windows 已保护你的电脑”（未知发布者），请点击“更多信息”，
   然后点击“仍要运行”。这不是病毒：Conso Token 是一个自制的小程序，没有付费发布者的签名，所以 Windows
   第一次会提示。它不使用任何网络功能。如果第 2 步成功，窗口会直接显示你的数据；否则会显示“暂未收到任何
   数字”：请告诉把应用给你的人。

“对话”页（自 1.3.0 起）及之后的新增内容
版本 1.3.8。自 1.3.4 以来的新内容：可手写第 3 到第 8 组（见下文）；发送记录移到了数据文件夹；部分界面
的措辞更易懂，八种语言都已更新。
在“本周”旁边，“对话”页会显示最近 24 小时内的每个 Claude Code 对话：它已经占了多少（即它的上下文；约数，≈），
以及离“交接”还剩多少——交接就是该换一个新对话继续的时刻。进度条上，奶油色标记是交接，虚线是“注意”；
“已摘要”表示 Claude 为缩短该对话而做了摘要（立即交接）。闲置超过 30 分钟的对话会折叠在“另有 n 个”下面。
- 初始设置：只有一组，注意线 70%，交接线 80%。点击“设置”按钮会打开一个窗口：可分为两组（组名由你自己
  输入；此时点击某一行的标签，会把整个文件夹移到另一组）、两个阈值滑块和一条试验条、“各模型的对话容量”
  （自动、200 000 或 1 000 000）、闪烁的圆点、数字动画。所有更改立即生效，并保存在数据文件夹中的
  conversations.txt 里。“恢复默认”可回到初始值（需再点击一次确认）。
- 第一次停留在“对话”页且有可供分组的对话时，会弹出一个窗口询问是否要分组（它只会自动弹出一次）：你勾选第一组的文件夹，并自己给各组命名（只需要输入组名）。点击“对话”页右上角（或“设置”里）的“选择分组…”按钮，可随时再次打开，次数不限：改回只有一组、给各组改名、全部取消勾选。不会丢失任何内容：你的选择保存在 conversations.txt 中。
- 两组以上（自 1.3.5 起），需手写：第 3 到第 8 组，每组有各自的提醒线。请先在“设置”中勾选“分为两组”
  （只有勾选后才会显示这些组）。关闭 Conso Token 窗口（窗口开着时，它会按内存中的内容重写该文件，
  你的修改会丢失）。用记事本打开数据文件夹中的 conversations.txt，在末尾添加行，并以 UTF-8 保存。
  组号写在每个关键字末尾，关键字用小写；例如：
      nom3=Reviews
      attention3=40
      passation3=55
      titre3=Review
  nom3= 是显示的组名（最多 24 个字符；不写则为“第 3 组”）。attention3= 和 passation3= 是注意线和
  交接线（10 到 95；不写则为 70 和 80）。titre3= 是标题的开头；groupe3= 是工作文件夹的名称，必须写得
  完全一致。每个标题开头或每个文件夹各写一行。对话先按标题归组，再按文件夹归组，最后才归入界面上的
  两个组。标题开头按完整的词匹配，不区分大小写：它后面必须是一个空格，或者标题到此结束（“Review”能
  匹配“Review of the plan”，但不匹配“Review: plan”或“Reviews”）。中文标题同样如此：开头之后要有空格。
  这类组中各行的标签不能点击。“设置”里不显示这些组；程序重写文件时会保留你写的行。“恢复默认”会删除
  它们；“只保留一组”只是把它们隐藏起来，并不删除。你在那里写的内容（组名、文件夹名、标题开头）只保存在
  你电脑上的这个文件里。
- “对话”按钮上的闪烁圆点在“本周”页面也能看到：到交接线为粉红色，到注意线为琥珀色。没有声音，也没有
  Windows 通知。
- “本周”页面的三张卡片会在打开时和每次更新时让数字滚动。要关闭：取消“设置”里的复选框，或关闭 Windows
  的“动画效果”设置。
- 每一行右侧的 ✕ 可以隐藏该对话：这一行会从列表、“另有 n 个”和闪烁的圆点中消失，即使之后有新消息也一样（适合已归档或测试用的对话）。点一下即可。“设置”里会显示“已隐藏 n 个对话”和“重新显示”按钮（仅在有隐藏对话时出现）；“恢复默认”不会动它们。当你用 ✕ 隐藏一个对话时，应用会把该对话的会话标识符（只是一串代码，不含标题和内容）写入自己的数据文件夹（conversations.txt），使它保持隐藏；当其最后一条消息超过 24 小时，或你点击“重新显示”时，该标识符即被清除。
- 只保留这台电脑上 Claude Code 文件里的计数（日期、模型、token 数量、文件夹名称）以及 Claude 应用所显示的每个对话的标题（用来在列表中为对话命名；取自已读取的文件，只在显示期间保存在内存中，绝不写入或发送），消息的文字从不保留，也绝不写入或发送。
  定时任务运行和子代理不计入。一个对话能装多少内容没有写在任何文件里，所以百分比只是近似值（≈）；如有需要，请在
  “设置”里按模型选择正确的容量。如果 Claude 更改了文件格式，列表会提示，而不会显示错误的数字。列表依据的是 Claude 的最后一条消息，而不是窗口的状态：已归档或已关闭的对话，只要最后一条消息不到 24 小时，就会一直显示（可用 ✕ 将其隐藏）；已打开但超过 24 小时没有消息的对话不会出现（Claude 一旦在其中回复就会重新出现）。限制：如果 Claude 更改了其行的类型，或再也找不到它的回答，列表会保持为空且没有任何提示；如果带有标题的那一行发生变化，名称会恢复为“文件夹 · 4 个字符”，且不会报错。标题只在文件的最后 64 KB 中查找：程序运行期间会一直保留，但重启后，很长且没有近期标题行的对话会恢复为“文件夹 · 4 个字符”。“设置”中的模型列表顺序固定（Opus、Sonnet、Haiku，然后是其他），但只保留最近的五个模型：24 小时内见到六个或更多模型时，第六个模型作出回答会改变列表内容。从第一次读取起，程序还会在数据文件夹中创建 contextes_vus.txt（记录每个模型见过的最大上下文，只有数字）。
注意事项
- 窗口会自动读取你的每周重置时间，并使用你自己的时区和夏令时/冬令时。在换季时间的那一周，倒计时下方会
  有一行文字说明（例如“提前1小时：10月25日 星期日起改用冬令时。”），这是正常的，无需调整。
- 窗口中的“一天”= 从该重置时间起的 24 小时，图表上方的文字有说明。
- Claude 桌面应用必须保持打开（不一定在前台），数据才会更新。Conso Token 窗口本身可以关闭：双击
  conso_token.exe 即可重新打开。
- 如果以后移动文件夹，任务将找不到程序：请把第 2 步的那句话连同新路径再发给 Claude 一次。
- 该任务显示的标题是“Conso Token feed”（标识符为 conso-token-feed），位于左侧栏的计划任务部分
  （“Scheduled”），或“Code”标签页的“Routines”中，具体取决于 Claude 应用的版本（在你的语言中名称可能
  不同）。它本身会像任何任务一样消耗一点套餐额度：已计入所显示的数据。如果删除它，数据就不再更新。
  每次运行结束时会自动归档：在归档中看到“Conso Token feed”会话是正常的。
- 数据保存在 C:\Users\<你的用户名>\AppData\Local\ConsoToken。
- 可以用窗口右上角的按钮切换语言。
- 许可证（字体和 Slint）在“licences”文件夹中。
- 从旧版本升级：关闭窗口，替换整个文件夹，然后把第 2 步的那句话再发给 Claude 一次。数据文件夹会保留。

如何删除
1. 关闭 Conso Token 窗口。
2. 在 Claude 桌面应用中删除任务“Conso Token feed”（conso-token-feed）（在计划任务部分，或“Code”
   标签页的“Routines”中）。只删除文件夹是不够的：该任务仍会每 15 分钟打开一个短会话，什么也发送
   不出去，却照样消耗一点套餐额度。
3. 仅当添加过运行 Conso Token 的 Claude Code 状态行时（第 2 步的安装从不添加）：它在
   C:\Users\<你的用户名>\.claude 中的 settings.json 文件里，位于包含“conso_token.exe --pont”的
   “statusLine”部分。请先复制一份该文件。如果“--pont”后面没有其他内容，删除这个“statusLine”部分。
   如果其中有“--suite”且后面跟着另一条命令，那就是你原来的状态行：保留“statusLine”，在它的
   “command”中只留下“--suite”后面的那条命令。其他内容不要改动。
4. 删除 Conso Token 文件夹。
5. 可选：如果还想清除你的设置和数据历史记录，请删除数据文件夹
   C:\Users\<你的用户名>\AppData\Local\ConsoToken。
没有 Conso Token，Claude 照常工作。

如果什么都没有收到
安装后请等待 15 到 20 分钟，并保持 Claude 桌面应用打开。仍然什么都没有？在文件资源管理器中点击地址栏，
输入 %USERPROFILE%\AppData\Local\ConsoToken 并按回车，然后用记事本打开 dernier_envoi.txt（完整路径：
%USERPROFILE%\AppData\Local\ConsoToken\dernier_envoi.txt）。它不再位于“outils”文件夹中。发送成功时，
这一行里有“rc=0”。请把里面的内容（或文件不存在）连同窗口截图告诉把应用给你的人。如果一直什么都
收不到，可以按上面的说明删除本应用。
