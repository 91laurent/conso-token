CONSO TOKEN — 1ページ説明

Conso Token は無料です。使用・コピー・改変・共有は自由です（MIT ライセンス、LICENSE.txt を参照）。

これは何をするものか
Claude のプランの使用状況を示す小さなウィンドウです。これまでの使用量、1日ごとの残り、予定より速いか遅いかが
分かります。予測はせず、どのサイトにも接続せず、パスワードも求めません。

必要なもの
- Windows 10 または 11。ほかにインストールするものはありません。
- Claude デスクトップアプリ（Claude Code を使っているもの）と Pro または Max プラン。ほかのプランではプランの
  数値がありません。

セットアップ（10分、1回だけ）
1. 受け取った「Conso Token」フォルダーを、パソコンのドライブ（例：H:）に置きます。zip で届いた場合は、zip を
   右クリックして「すべて展開」を選びます。フォルダー全体を残してください：conso_token.exe、「outils」フォルダー、
   「licences」フォルダー、テキストファイル。USB メモリやネットワークドライブは避け、フォルダー名にアポストロフィ
   を含めないでください。
2. Claude デスクトップアプリで新しい Claude Code セッションを開き、次の文を入力します（パスは自分のフォルダーに
   置き換えます）：
       フォルダー「H:\Conso Token」にある PASTE_INTO_CLAUDE.txt を読み、書かれているとおりに実行してください。
   Claude は、15分ごとに数値をウィンドウへ送るタスクを作成し、目の前で1回試して、成功したかどうかを伝えます。
   アプリが PowerShell の許可を求めたら「はい」または「常に許可」と答えてください。数値を送るために必要です。
3. conso_token.exe をダブルクリックします。Windows に「Windows によって PC が保護されました」（不明な発行元）と
   表示されたら、「詳細情報」→「実行」をクリックします。ウイルスではありません。Conso Token は有料の発行元の
   署名がない手作りの小さなプログラムなので、初回は Windows が警告します。ネットワーク機能は使いません。
   手順2が成功していれば、ウィンドウにはすでに数値が表示されます。そうでなければ「数値をまだ受信していません」と
   表示されます。アプリをくれた人に伝えてください。

1.3.0 の新機能：「会話」タブ
「週」の隣にある「会話」タブには、直近24時間の Claude Code の会話ごとに、コンテキストがどれだけ埋まって
いるか（概算、≈）と、引き継ぎまでの残りが表示されます。引き継ぎとは、新しい会話に移って続けるタイミング
のことです。バーでは、クリーム色の線が引き継ぎ、点線が注意です。「要約済み」は Claude がその会話を圧縮した
ことを表します（すぐに引き継ぎ）。30分以上動きのない会話は「他 n 件」にたたまれます。
- 初期設定：グループは1つ、注意は70%、引き継ぎは80%。「設定」ボタンでウィンドウが開きます：2つのグループに
  分ける（名前は自分で入力。分けると、行のラベルをクリックしてフォルダーごと別のグループへ移せます）、
  しきい値の2本のスライダーと試し用バー、モデルごとのコンテキストウィンドウ（自動、200 000、1 000 000）、
  点滅するドット、数字のアニメーション。変更はすぐに反映され、データフォルダーの conversations.txt に
  保存されます。「初期値に戻す」で最初の状態に戻ります（確認のためもう一度押します）。
- 「会話」タブを初めて開くと、会話をグループに分けるかどうかを尋ねるウィンドウが出ます。最初のグループのフォルダーにチェックを入れ、グループの名前を自分で付けます（入力するのは名前だけです）。「会話」タブの右上と「設定」にある「グループを選ぶ…」ボタンで、いつでも何度でも開き直せます（1つのグループに戻す、グループ名を変える、すべてのチェックを外す）。何も失われません。選択は conversations.txt に保存されます。
- 「会話」ボタンの点滅するドットは「週」画面でも見えます：引き継ぎでピンク、注意で琥珀色。音も Windows の
  通知もありません。
- 「週」画面の3枚のカードは、開いたときと更新のたびに数字がアニメーションで動きます。止めるには「設定」の
  チェックボックス、または Windows の「アニメーション効果」の設定を使います。
- 各行の右端にある ✕ で会話を非表示にできます。その行は一覧、「他 n 件」、点滅するドットから消え、新しいメッセージが届いても戻りません（アーカイブ済みの会話やテスト用の会話に便利です）。クリック1回で済みます。「設定」には「非表示の会話：n件」と「再表示」ボタンが出ます（非表示の会話があるときだけ）。「初期値に戻す」はこれに触れません。✕ で会話を非表示にすると、アプリはその会話のセッション ID（ただのコードで、タイトルも内容も含みません）を自分のデータフォルダー（conversations.txt）に書き込み、非表示を保ちます。最後のメッセージから 24 時間が過ぎるか、「再表示」を押すと、この ID は消去されます。
- このパソコンの Claude Code のファイルから保持するのはカウンター（日付、モデル、トークン数、フォルダー名）
  と、Claude アプリに表示される各会話のタイトル（一覧で会話を見分けるため。すでに読んでいるファイルから取得し、表示している間だけメモリに保持し、書き込みも送信もしません）だけで、メッセージの文章は保持せず、書き込みも送信もしません。スケジュール実行とサブエージェントは除外されます。ウィンドウの
  大きさはどのファイルにも書かれていないため、パーセンテージは概算（≈）です。必要なら「設定」でモデルごとに
  正しいウィンドウを選んでください。Claude がファイル形式を変えた場合は、誤った数値を出さずに、その旨が
  表示されます。一覧は Claude の最後のメッセージを基準にしており、ウィンドウの状態は見ていません。アーカイブ済みまたは閉じた会話は、最後のメッセージから 24 時間以内なら表示されたままです（✕ で非表示にできます）。開いていても 24 時間以上メッセージがない会話は表示されません（Claude が返答すると再び表示されます）。制限：Claude が行の種類（type）を変えた場合や、その返答が見つからなくなった場合、一覧は警告なしに空のままになります。タイトルを持つ行の形式が変わった場合は、名前が「フォルダー · 4文字」に戻り、エラーは出ません。タイトルはファイルの最後の 64 KB から探します。プログラムが動いている間は保持されますが、再起動すると、最近のタイトル行がない非常に長い会話は「フォルダー · 4文字」に戻ります。「設定」のモデル一覧は並び順が固定（Opus、Sonnet、Haiku、その他）ですが、保持するのは直近の 5 モデルです。24 時間に 6 モデル以上を見た場合、6 番目のモデルが応答すると一覧の内容が変わります。最初に読み取った時点で、データフォルダーに contextes_vus.txt も作られます（モデルごとに見た最大のコンテキスト。数字だけです）。
知っておくこと
- ウィンドウは、週のリセット時刻を自動で読み取り、あなたのタイムゾーンと夏時間・冬時間の切り替えに従います。
  時刻が切り替わる週は、カウントダウンの下に説明の一行が表示されます（例：「1時間早い：10月25日 日曜日に冬時間へ切り替わります。」）。正常ですので、調整は不要です。
- ウィンドウでの「1日」は、そのリセットから24時間です（グラフの上の文に書かれています）。
- 数値が更新されるには、Claude アプリが開いている必要があります（前面でなくても構いません）。Conso Token の
  ウィンドウは閉じてもよく、conso_token.exe をダブルクリックすればまた開けます。
- フォルダーを後で移動すると、タスクがプログラムを見つけられなくなります。手順2の文を新しいパスで Claude に
  もう一度伝えてください。
- タスク「conso-token-feed」（左サイドバーの「スケジュール済み」）は、ほかのタスクと同様にプランを少し消費します。
  表示される数値に含まれています。削除すると数値は更新されなくなります。実行のたびに自動でアーカイブされるので、
  アーカイブに「Conso Token feed」のセッションがあっても正常です。
- すべて停止するには、そのタスクを削除してから Conso Token フォルダーを削除します。
- データは C:\Users\<あなたの名前>\AppData\Local\ConsoToken に保存されます。
- 言語は、ウィンドウ右上のボタンで切り替えられます。
- ライセンス（フォントと Slint）は「licences」フォルダーにあります。

何も届かないとき
メモ帳で「outils\dernier_envoi.txt」（Conso Token フォルダー内）を開き、その内容（またはファイルがないこと）を、
ウィンドウのスクリーンショットとともに、アプリをくれた人に伝えてください。
