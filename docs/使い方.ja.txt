CONSO TOKEN — 1ページ説明

Conso Token は無料です。使用・コピー・改変・共有は自由です（MIT ライセンス、LICENSE.txt を参照）。

これは何をするものか
Claude のプランの使用状況を示す小さなウィンドウです。これまでの使用量、1日ごとの残り、予定より速いか遅いかが
分かります。予測はせず、どのサイトにも接続せず、パスワードも求めません。

必要なもの
- Windows 10 または 11。ほかにインストールするものはありません。
- Claude デスクトップアプリ（Claude Code を使っているもの）と、アプリが利用状況の数値を提供する有料の Claude
  プラン。数値が提供されないプランもあります。Conso Token を試したのは1つのプランだけです。

セットアップ（10分、1回だけ）
1. 受け取った「Conso Token」フォルダーを、パソコンのドライブ（例：H:）に置きます。zip で届いた場合は、zip を
   右クリックして「すべて展開」を選びます。フォルダー全体を残してください：conso_token.exe、「outils」フォルダー、
   「licences」フォルダー、テキストファイル。USB メモリやネットワークドライブは避け、フォルダー名にアポストロフィ
   を含めないでください。
2. Claude デスクトップアプリで新しい Claude Code セッションを開き、次の文を入力します（パスは自分のフォルダーに
   置き換えます）：
       フォルダー「H:\Conso Token」にある PASTE_INTO_CLAUDE.txt を読み、書かれているとおりに実行してください。
   Claude は、15分ごとに数値をウィンドウへ送るタスクを作成し、目の前で1回試して、成功したかどうかを伝えます。
   アプリが PowerShell の許可を求めたら「はい」または「常に許可」と答えてください。数値を送るために必要です。
3. conso_token.exe をダブルクリックします。Windows に「Windows によって PC が保護されました」（不明な発行元）と
   表示されたら、「詳細情報」→「実行」をクリックします。ウイルスではありません。Conso Token は有料の発行元の
   署名がない手作りの小さなプログラムなので、初回は Windows が警告します。ネットワーク機能は使いません。
   手順2が成功していれば、ウィンドウにはすでに数値が表示されます。そうでなければ「まだ数値を受信していません」と
   表示されます。アプリをくれた人に伝えてください。

「会話」タブ（1.3.0 から）と、その後に加わったこと
バージョン 1.3.8。1.3.4 からの変更点：手書きで追加するグループ 3〜8（下記）、送信ログのデータフォルダーへの移動、
一部の画面の言葉をわかりやすく（8言語すべて）。
「週」の隣にある「会話」タブには、直近24時間の Claude Code の会話ごとに、どれだけ埋まって
いるか（コンテキスト。概算、≈）と、引き継ぎまでの残りが表示されます。引き継ぎとは、新しい会話に移って続けるタイミング
のことです。バーでは、クリーム色の線が引き継ぎ、点線が注意です。「要約済み」は Claude がその会話を短くするために
要約したことを表します（すぐに引き継ぎ）。30分以上動きのない会話は「他 n 件」にたたまれます。
- 初期設定：グループは1つ、注意は70%、引き継ぎは80%。「設定」ボタンでウィンドウが開きます：2つのグループに
  分ける（名前は自分で入力。分けると、行のラベルをクリックしてフォルダーごと別のグループへ移せます）、
  しきい値の2本のスライダーと試し用バー、「モデルごとの会話の容量」（自動、200 000、1 000 000）、
  点滅するドット、数字のアニメーション。変更はすぐに反映され、データフォルダーの conversations.txt に
  保存されます。「初期値に戻す」で最初の状態に戻ります（確認のためもう一度押します）。
- 初めて「会話」タブを表示していて、分ける候補の会話があるときに、会話をグループに分けるかどうかを尋ねるウィンドウが出ます（自動で開くのは一度だけです）。最初のグループのフォルダーにチェックを入れ、グループの名前を自分で付けます（入力するのは名前だけです）。「会話」タブの右上と「設定」にある「グループを選ぶ…」ボタンで、いつでも何度でも開き直せます（1つのグループに戻す、グループ名を変える、すべてのチェックを外す）。何も失われません。選択は conversations.txt に保存されます。
- 3つ以上のグループ（1.3.5 から、手書き）：グループ 3〜8 を追加でき、それぞれに通知のレベルがあります。まず
  「設定」で「2つのグループに分ける」にチェックを入れます（チェックがあるときだけ表示されます）。次に Conso Token の
  ウィンドウを閉じます（開いていると、メモリの内容でファイルを書き直すため、変更が失われます）。データフォルダーの
  conversations.txt をメモ帳で開き、末尾に行を追加して UTF-8 で保存します。各キーは小文字で、末尾にグループ番号を
  付けます。例：
      nom3=Reviews
      attention3=40
      passation3=55
      titre3=Review
  nom3= は表示する名前（最大24文字。書かなければ「グループ3」）。attention3= と passation3= は注意と引き継ぎ
  （10〜95。書かなければ 70 と 80）。titre3= はタイトルの書き出し、groupe3= は作業フォルダーの名前（正確に）。
  タイトルの書き出しごと、またはフォルダーごとに1行です。会話はまずタイトル、次にフォルダーで振り分けられ、
  最後に画面の2つのグループに入ります。タイトルの書き出しは単語単位で、大文字と小文字は区別しません。直後に
  空白があるか、そこでタイトルが終わる必要があります（「Review」は「Review of the plan」に一致し、
  「Review: plan」や「Reviews」には一致しません）。日本語のタイトルでも、書き出しの後に空白が必要です。この
  グループの行のラベルはクリックできません。「設定」には表示されません。プログラムはファイルを書き直すときも
  これらの行を残します。「初期値に戻す」で消えます。「グループは1つのまま」では消えずに非表示になります。そこに
  書いた内容（グループ名、フォルダー名、タイトルの書き出し）は、お使いのパソコンのこのファイルに残ります。
- 「会話」ボタンの点滅するドットは「週」画面でも見えます：引き継ぎでピンク、注意で琥珀色。音も Windows の
  通知もありません。
- 「週」画面の3枚のカードは、開いたときと更新のたびに数字がアニメーションで動きます。止めるには「設定」の
  チェックボックス、または Windows の「アニメーション効果」の設定を使います。
- 各行の右端にある ✕ で会話を非表示にできます。その行は一覧、「他 n 件」、点滅するドットから消え、新しいメッセージが届いても戻りません（アーカイブ済みの会話やテスト用の会話に便利です）。クリック1回で済みます。「設定」には「非表示の会話：n件」と「再表示」ボタンが出ます（非表示の会話があるときだけ）。「初期値に戻す」はこれに触れません。✕ で会話を非表示にすると、アプリはその会話のセッション ID（ただのコードで、タイトルも内容も含みません）を自分のデータフォルダー（conversations.txt）に書き込み、非表示を保ちます。最後のメッセージから 24 時間が過ぎるか、「再表示」を押すと、この ID は消去されます。
- このパソコンの Claude Code のファイルから保持するのはカウンター（日付、モデル、トークン数、フォルダー名）
  と、Claude アプリに表示される各会話のタイトル（一覧で会話を見分けるため。すでに読んでいるファイルから取得し、表示している間だけメモリに保持し、書き込みも送信もしません）だけで、メッセージの文章は保持せず、書き込みも送信もしません。スケジュール実行とサブエージェントは除外されます。1つの会話に
  どれだけ入るかはどのファイルにも書かれていないため、パーセンテージは概算（≈）です。必要なら「設定」でモデルごとに
  正しい容量を選んでください。Claude がファイル形式を変えた場合は、誤った数値を出さずに、その旨が
  表示されます。一覧は Claude の最後のメッセージを基準にしており、ウィンドウの状態は見ていません。アーカイブ済みまたは閉じた会話は、最後のメッセージから 24 時間以内なら表示されたままです（✕ で非表示にできます）。開いていても 24 時間以上メッセージがない会話は表示されません（Claude が返答すると再び表示されます）。制限：Claude が行の種類（type）を変えた場合や、その返答が見つからなくなった場合、一覧は警告なしに空のままになります。タイトルを持つ行の形式が変わった場合は、名前が「フォルダー · 4文字」に戻り、エラーは出ません。タイトルはファイルの最後の 64 KB から探します。プログラムが動いている間は保持されますが、再起動すると、最近のタイトル行がない非常に長い会話は「フォルダー · 4文字」に戻ります。「設定」のモデル一覧は並び順が固定（Opus、Sonnet、Haiku、その他）ですが、保持するのは直近の 5 モデルです。24 時間に 6 モデル以上を見た場合、6 番目のモデルが応答すると一覧の内容が変わります。最初に読み取った時点で、データフォルダーに contextes_vus.txt も作られます（モデルごとに見た最大のコンテキスト。数字だけです）。
知っておくこと
- ウィンドウは、週のリセット時刻を自動で読み取り、あなたのタイムゾーンと夏時間・冬時間の切り替えに従います。
  時刻が切り替わる週は、カウントダウンの下に説明の一行が表示されます（例：「1時間早い：10月25日 日曜日に冬時間へ切り替わります。」）。正常ですので、調整は不要です。
- ウィンドウでの「1日」は、そのリセットから24時間です（グラフの上の文に書かれています）。
- 数値が更新されるには、Claude アプリが開いている必要があります（前面でなくても構いません）。Conso Token の
  ウィンドウは閉じてもよく、conso_token.exe をダブルクリックすればまた開けます。
- フォルダーを後で移動すると、タスクがプログラムを見つけられなくなります。手順2の文を新しいパスで Claude に
  もう一度伝えてください。
- このタスクは「Conso Token feed」というタイトルで表示されます（ID は conso-token-feed）。場所は、Claude アプリの
  バージョンによって、左サイドバーのスケジュールタスクの欄（「Scheduled」）か、「Code」タブの「Routines」です
  （お使いの言語では名前が違って表示されることがあります）。ほかのタスクと同様にプランを少し消費し、
  表示される数値に含まれています。削除すると数値は更新されなくなります。実行のたびに自動でアーカイブされるので、
  アーカイブに「Conso Token feed」のセッションがあっても正常です。
- データは C:\Users\<あなたの名前>\AppData\Local\ConsoToken に保存されます。
- 言語は、ウィンドウ右上のボタンで切り替えられます。
- ライセンス（フォントと Slint）は「licences」フォルダーにあります。
- 以前のバージョンから更新するには：ウィンドウを閉じ、フォルダー全体を置き換えてから、手順2の文をもう一度
  Claude に伝えてください。データフォルダーはそのまま残ります。

削除するには
1. Conso Token のウィンドウを閉じます。
2. Claude デスクトップアプリで、タスク「Conso Token feed」（conso-token-feed）を削除します（スケジュールタスクの欄、
   または「Code」タブの「Routines」）。フォルダーを削除するだけでは不十分です。タスクは15分ごとに短いセッションを
   開き続け、何も送れないのに、プランは少し消費します。
3. Conso Token を実行する Claude Code のステータスラインを追加した場合のみ（手順2のセットアップが追加することは
   ありません）：C:\Users\<あなたの名前>\.claude の settings.json の中で、「conso_token.exe --pont」を含む
   「statusLine」の部分です。先にファイルのコピーを取ってください。「--pont」の後に何もなければ、その
   「statusLine」の部分を削除します。「--suite」の後に別のコマンドがある場合、それは以前から使っていた
   ステータスラインです。「statusLine」は残し、その「command」には「--suite」の後のコマンドだけを残してください。
   ほかは何も変えないでください。
4. Conso Token フォルダーを削除します。
5. 任意：設定と数値の履歴も消すには、データフォルダー C:\Users\<あなたの名前>\AppData\Local\ConsoToken を
   削除します。
Conso Token がなくても、Claude は同じように動きます。

何も届かないとき
セットアップの後、Claude デスクトップアプリを開いたまま15〜20分お待ちください。それでも届かない場合は、
エクスプローラーのアドレスバーをクリックして %USERPROFILE%\AppData\Local\ConsoToken と入力し、Enter を押してから、
メモ帳で dernier_envoi.txt を開きます（完全なパス：
%USERPROFILE%\AppData\Local\ConsoToken\dernier_envoi.txt）。このファイルは「outils」フォルダーにはもうありません。
送信に成功していれば、その行に「rc=0」があります。内容（またはファイルがないこと）を、ウィンドウの
スクリーンショットとともに、アプリをくれた人に伝えてください。いつまでも何も届かない場合は、上の手順で
アプリを削除できます。
