CONSO TOKEN — 1ページ説明

Conso Token は無料です。使用・コピー・改変・共有は自由です（MIT ライセンス、LICENSE.txt を参照）。

これは何をするものか
Claude のプランの使用状況を示す小さなウィンドウです。これまでの使用量、1日ごとの残り、予定より速いか遅いかが
分かります。予測はせず、どのサイトにも接続せず、パスワードも求めません。

必要なもの
- Windows 10 または 11。ほかにインストールするものはありません。
- Claude デスクトップアプリ（Claude Code を使っているもの）と Pro または Max プラン。ほかのプランではプランの
  数値がありません。

セットアップ（10分、1回だけ）
1. 受け取った「Conso Token」フォルダーを、パソコンのドライブ（例：H:）に置きます。zip で届いた場合は、zip を
   右クリックして「すべて展開」を選びます。フォルダー全体を残してください：conso_token.exe、「outils」フォルダー、
   「licences」フォルダー、テキストファイル。USB メモリやネットワークドライブは避け、フォルダー名にアポストロフィ
   を含めないでください。
2. Claude デスクトップアプリで新しい Claude Code セッションを開き、次の文を入力します（パスは自分のフォルダーに
   置き換えます）：
       フォルダー「H:\Conso Token」にある PASTE_INTO_CLAUDE.txt を読み、書かれているとおりに実行してください。
   Claude は、15分ごとに数値をウィンドウへ送るタスクを作成し、目の前で1回試して、成功したかどうかを伝えます。
   アプリが PowerShell の許可を求めたら「はい」または「常に許可」と答えてください。数値を送るために必要です。
3. conso_token.exe をダブルクリックします。Windows に「Windows によって PC が保護されました」（不明な発行元）と
   表示されたら、「詳細情報」→「実行」をクリックします。ウイルスではありません。Conso Token は有料の発行元の
   署名がない手作りの小さなプログラムなので、初回は Windows が警告します。ネットワーク機能は使いません。
   手順2が成功していれば、ウィンドウにはすでに数値が表示されます。そうでなければ「数値をまだ受信していません」と
   表示されます。アプリをくれた人に伝えてください。

知っておくこと
- ウィンドウは、週のリセット時刻を自動で読み取り、あなたのタイムゾーンと夏時間・冬時間の切り替えに従います。
  時刻が切り替わる週は、カウントダウンの下に説明の一行が表示されます（例：「1時間早い：10月25日 日曜日に冬時間へ切り替わります。」）。正常ですので、調整は不要です。
- ウィンドウでの「1日」は、そのリセットから24時間です（グラフの上の文に書かれています）。
- 数値が更新されるには、Claude アプリが開いている必要があります（前面でなくても構いません）。Conso Token の
  ウィンドウは閉じてもよく、conso_token.exe をダブルクリックすればまた開けます。
- フォルダーを後で移動すると、タスクがプログラムを見つけられなくなります。手順2の文を新しいパスで Claude に
  もう一度伝えてください。
- タスク「conso-token-feed」（左サイドバーの「スケジュール済み」）は、ほかのタスクと同様にプランを少し消費します。
  表示される数値に含まれています。削除すると数値は更新されなくなります。実行のたびに自動でアーカイブされるので、
  アーカイブに「Conso Token feed」のセッションがあっても正常です。
- すべて停止するには、そのタスクを削除してから Conso Token フォルダーを削除します。
- データは C:\Users\<あなたの名前>\AppData\Local\ConsoToken に保存されます。
- 言語は、ウィンドウ右上のボタンで切り替えられます。
- ライセンス（フォントと Slint）は「licences」フォルダーにあります。

何も届かないとき
メモ帳で「outils\dernier_envoi.txt」（Conso Token フォルダー内）を開き、その内容（またはファイルがないこと）を、
ウィンドウのスクリーンショットとともに、アプリをくれた人に伝えてください。
